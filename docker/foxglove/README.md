# Foxglove layout

`skuba_navigation.json` is a starter layout for watching and driving the nav
stack from Foxglove Studio. It is the navigation counterpart of
skuba-manipulation's `docker/foxglove/skuba_manipulation.json`.

It is generated by `generate_layout.py` with the official `foxglove-sdk`
Python API, not written by hand. The SDK docs say the layout JSON "includes
implementation details that aren't meant for manual editing". To change it,
edit the script and regenerate:

```bash
pip install foxglove-sdk
python docker/foxglove/generate_layout.py > docker/foxglove/skuba_navigation.json
```

## Running it

Nothing to start: every SKUBA container runs the bridge watcher from its
entrypoint, and one of them serves `ws://<robot-ip>:8765`. Foxglove Studio →
**Layouts** → **Import from file...** → `skuba_navigation.json`, then
**Open connection** → `ws://<robot-ip>:8765`.

## What the layout shows

| Panel | Source | Notes |
| --- | --- | --- |
| **Map** (3D, fixed frame `map`, follows `base_link`) | `/map`, `/global_costmap/costmap`, `/local_costmap/costmap`, `/local_costmap/published_footprint`, `/scan`, `/scan_filtered` (hidden), `/plan`, `/local_plan`, `/amcl_pose`, `/robot_description` | The panel's publish tool sends **Pose estimate** → `/initialpose` (AMCL) or **Pose** → `/goal_pose` (Nav2 goal) |
| **E-stop** | `/e_stop` (std_msgs/Bool) | Red when `emergency_stop` holds the twist_mux lock |
| **Door** | `/skuba/nav/door_status` (std_msgs/Bool) | Only publishes while `door_detector` is toggled on |
| **Teleop** | publishes `/cmd_vel_key` | twist_mux keyboard lane (priority 90): joystick and e-stop still override it |
| **rosout** / **cmd_vel** tabs | `/rosout`; `/cmd_vel`, `/cmd_vel_nav` | Log, and the velocity the base gets vs. what Nav2 asks for |

## Nodes the stack runs

`cheesecake_nav.launch.py` starts these. Check what is actually up with
`ros2 node list` inside the container.

| Group | Nodes |
| --- | --- |
| Hardware (`skuba_bringup`) | `robot_state_publisher`, `kobuki_node`, `sllidar_node`, `camera/camera` (RealSense), `joy_node`, `teleop_twist_joy_node`, `joy_smoother` |
| Localization (nav2) | `map_server`, `amcl`, `lifecycle_manager_localization` |
| Navigation (nav2) | `controller_server`, `smoother_server`, `planner_server`, `behavior_server`, `bt_navigator`, `waypoint_follower`, `velocity_smoother`, `lifecycle_manager_navigation` |
| Extras (`nav2_bringup_launch.py`) | `filter_lidar`, `base_link_to_laser_tf`, `emergency_stop`, `twist_mux` |
| SKUBA services | `navigation_server`, `save_location`, `door_detector`, `costmap_reconfig_server` |
| Visualization | `rviz2` (`use_rviz`); `foxglove_bridge_<subsystem>` from whichever container serves 8765 |
